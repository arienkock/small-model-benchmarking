The bug in the function is in the return statement. It divides the total sum by `len(total)`, but `total` is a number (the sum), not a collection. Calling `len()` on a number raises a `TypeError`. It should divide by `len(values)` instead.

```python
def average(values):
    total = 0
    for x in values:
        total += x
    return total / len(values)
```

```python
        total += x
    return total / len(values)
```
