  <name>.pkg  = the file exactly as shipped. Does it load and run?
                PASS | FAIL | MISSING
algo:PASS + pkg:FAIL is a correct algorithm killed by its own scaffolding.

        never called the function and has no evidence either way — it is
        not a quiet FAIL. See SPLIT.txt for the per-model totals.
