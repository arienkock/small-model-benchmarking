Build a rate-limited API.

Create two files:

1. server.py — HTTP server using only the Python standard library:
   - GET /api/time returns {"now": <unix timestamp>}.
   - A per-client rate limit of 5 requests per 60 seconds, keyed by client IP.
   - The 6th and further requests within the window return 429 with a Retry-After header.
2. throttle.ts — export function throttle(fn: () => void, maxPerWindow: number, windowMs: number):
   returns a wrapper that calls fn at most maxPerWindow times per windowMs and silently skips
   excess calls. Include a brief self-test that passes when run with: node throttle.ts

Use only the Python standard library. Do not install packages.
Verify before finishing: curl /api/time six times in a row and show that the 6th returns 429.
