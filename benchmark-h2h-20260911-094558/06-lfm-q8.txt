**Solution Explanation**

We need the first character in the string `s` that appears **exactly once**.  
A straightforward way is:

1. **Count how many times each character occurs** – one pass over the string.  
   This can be done with a dictionary (hash map) in `O(n)` time.
2. **Scan the string a second time** and return the first character whose count is `1`.  
   Because we walk the string in order, the first such character is the answer.

Both passes are linear, so the whole algorithm runs in `O(n)` time.  
The dictionary holds at most one entry per distinct character, i.e. `O(k)` extra space
(`k ≤ n`). This satisfies the required linear‑time constraint.

---

### Code

```python
def first_unique(s: str):
    """
    Returns the first character in `s` that occurs exactly once.
    If no such character exists, returns None.

    Time   : O(n) – two linear passes over the string
    Space  : O(k) – dictionary of character frequencies (k = number of distinct chars)
    """
    # 1️⃣ Count frequencies
    freq = {}
    for ch in s:
        freq[ch] = freq.get(ch, 0) + 1

    # 2️⃣ Find the first character with frequency 1
    for ch in s:
        if freq[ch] == 1:
            return ch

    # No unique character found
    return None

    assert first_unique("aabbcc") is None

    # Example 3: "abcab" → 'c' is the first unique character
    assert first_unique("abcab") == 'c'

    print("All test cases passed.")
```
