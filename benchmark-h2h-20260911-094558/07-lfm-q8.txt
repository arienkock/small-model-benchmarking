**Bug:**  
The function divides by `len(total)` – but `total` is a numeric sum, not a collection. It should divide by the number of elements in the input list, i.e. `len(values)`. Additionally, if `values` is empty the function will raise a `ZeroDivisionError`.

**Corrected version**

```python
def average(values):
    """Return the arithmetic mean of a non‑empty list of numbers."""
    if not values:                     # guard against an empty sequence
        raise ValueError("Cannot compute average of an empty sequence")

    total = 0
    for x in values:
        total += x

    return total / len(values)         # divide by the number of elements
```

*Explanation:*  
- `len(values)` gives the correct count of items.  
- The explicit check for an empty list prevents a `ZeroDivisionError`.  
- Using `sum(values)` (or the loop shown) is equivalent to the original accumulation logic.
