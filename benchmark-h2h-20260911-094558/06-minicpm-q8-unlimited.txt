```
def first_unique(s):
    """
    Return the first character in string s that appears exactly once.
    Return None if no such character exists.
    Time complexity: O(n)
    Space complexity: O(k) where k is number of distinct characters in s.
    """
    if not s:
        return None

    # Count occurrences
    counts = {}
    for ch in s:
        counts[ch] = counts.get(ch, 0) + 1

    # Find first char with count 1
    for ch in s:
        if counts[ch] == 1:
            return ch

    return None
```

Here is a compact O(n) solution that counts the occurrences of each character once and then scans the original string to find the first character whose count is 1.  
The function returns `None` if no such character exists.

```python
def first_unique(s: str):
    """
    Return the first character in `s` that occurs exactly once.
    If every character appears more than once (or the string is empty)
    return None.

    Time   : O(n) – one pass for counting, one pass for the search.
    Space  : O(k) – k = number of distinct characters in `s`.
    """
    # Fast exit for empty string
    if not s:
        return None

    # Count each character
    counts = {}
    for ch in s:
        counts[ch] = counts.get(ch, 0) + 1

    # Find the first character with a count of 1
    for ch in s:
        if counts[ch] == 1:
            return ch

    # No unique character found
    return None
```

**Explanation of the algorithm**

1. **Counting phase** – Iterate over `s` once, storing the frequency of each character in a dictionary (`counts`). This gives us the exact multiplicity of every character.

2. **Selection phase** – Walk through `s` again in its original order. The first character whose stored count equals 1 is the answer; because we preserve the original order, this is guaranteed to be the *first* unique character.

Both phases together visit each character a constant number of times, so the overall time complexity is `O(n)`. The extra space used is proportional to the number of distinct characters, i.e. `O(k)` where `k ≤ len(s)`.
